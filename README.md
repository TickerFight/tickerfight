## Come si usa

Serve Python 3.12 o più recente. Entra nella cartella di un articolo e segui il suo README: si crea un ambiente virtuale, si installano le librerie di `requirements.txt` e si lanciano gli script di `flusso/` nell'ordine indicato.

## Avvertenze

Sono simulazioni su dati passati, a scopo didattico: non sono consigli di investimento e i risultati passati non garantiscono quelli futuri.
