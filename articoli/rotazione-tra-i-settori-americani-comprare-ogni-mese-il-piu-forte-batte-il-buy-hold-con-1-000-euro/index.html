Rotazione tra i settori americani: comprare ogni mese il più forte batte il buy & hold, con 1.000 euro?

Se ogni mese si compra il settore americano che ha reso di più negli ultimi mesi, con 1.000 € di capitale, commissioni per ordine e tassa del 26%, si batte il semplice buy & hold dell'S&P 500? Condizioni di chi parte con poco: commissione per ordine in tre scenari, tassa con minusvalenze riportate, azioni frazionate.

Il disegno

  • Regola: all'ultima seduta di ogni mese si calcola il rendimento di prezzo degli ultimi L giorni di borsa dei nove ETF settoriali SPDR e si scelgono i K migliori; l'ordine parte alla chiusura della prima seduta del mese dopo (nessun look-ahead). Si vendono i settori usciti dalla classifica e si comprano quelli entrati. Regola principale: L = 126 (circa sei mesi), K = 1.
  • Prove dichiarate in anticipo: L in {63, 126, 252} e K in {1, 3}, cioè sei rotazioni, nessuna scelta a posteriori.
  • Strumenti: XLB, XLE, XLF, XLI, XLK, XLP, XLU, XLV, XLY (dollari, convertiti in euro con il cambio del giorno); riferimenti: ETF sull'S&P 500 (SPY) tenuto e i nove settori tenuti in parti uguali.
  • Condizioni: 1.000 €; commissione 0 €, 2 € a ordine e 0,1% dell'importo; tassa 26% con compensazione delle minusvalenze; dividendi e imposta di bollo non considerati.
  • Test: scimmie (stessi giorni di ordine e stesso numero di ordini, settore scelto a caso; una coda) e bootstrap a blocchi della differenza di rendimento giornaliero tra rotazione e buy & hold, per le due rotazioni a sei mesi, con la correzione di Holm.

"""Passo 1 - Scarica da Yahoo Finance le serie giornaliere dei nove ETF settoriali, dell'ETF sull'S&P 500 e del cambio euro-dollaro.

Salva dati/<ticker>.csv (Date, Open, High, Low, Close, Volume) e dati/metadati.json con la fonte, la data del download,
la versione di yfinance e l'impronta SHA-256 di ogni file. Gli script successivi leggono SOLO i file salvati: i risultati
restano riproducibili anche se Yahoo corregge i dati in futuro.
"""
import hashlib
import json
import time
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

import pandas as pd
import yfinance as yf

import config


def scarica(ticker: str) -> pd.DataFrame:
    for tentativo in range(3):
        grezzo = yf.Ticker(ticker).history(start=config.INIZIO_DOWNLOAD, auto_adjust=False)
        if not grezzo.empty:
            return grezzo
        print(f"{ticker}: nessun dato (tentativo {tentativo + 1})")
        time.sleep(10)
    return pd.DataFrame()


def main() -> None:
    config.DATI.mkdir(parents=True, exist_ok=True)
    ora_borsa = datetime.now(ZoneInfo(config.FUSO_BORSA))
    meta = {"fonte": "Yahoo Finance", "url_fonte": config.URL_FONTE, "libreria": f"yfinance {yf.__version__}",
            "scaricato_il_utc": datetime.now(timezone.utc).isoformat(timespec="seconds"), "strumenti": []}
    elenco = [(t, n, "USD") for t, n in config.SETTORI] + [(config.BENCHMARK[0], config.BENCHMARK[1], "USD"),
                                                           (config.TICKER_CAMBIO, "cambio euro-dollaro", "USD")]
    for ticker, nome, valuta in elenco:
        riga = {"ticker": ticker, "nome": nome, "valuta": valuta}
        grezzo = scarica(ticker)
        if grezzo.empty:
            riga["stato"] = "scartato: nessun dato restituito da Yahoo Finance"
            meta["strumenti"].append(riga)
            continue
        df = grezzo[["Open", "High", "Low", "Close", "Volume"]].copy()
        df.index = pd.to_datetime(df.index).tz_localize(None).normalize()
        df.index.name = "Date"
        df = df[~df.index.duplicated(keep="last")].sort_index().dropna(subset=["Close"])
        df = df[df["Close"] > 0]
        if df.index[-1].date() == ora_borsa.date() and ora_borsa.hour < 17:       # seduta in corso: barra incompleta
            df = df.iloc[:-1]
        salti = (df["Close"].pct_change().abs() > 0.25).sum()
        file = config.file_dati(ticker)
        df.to_csv(file, float_format="%.6f")
        riga.update({"stato": "ok", "file": file.name, "righe": len(df), "prima_data": str(df.index[0].date()),
                     "ultima_data": str(df.index[-1].date()), "variazioni_giornaliere_oltre_25_per_cento": int(salti),
                     "sha256": hashlib.sha256(file.read_bytes()).hexdigest()})
        meta["strumenti"].append(riga)
        print(f"{ticker}: {len(df)} righe, dal {riga['prima_data']} al {riga['ultima_data']}, salti oltre il 25%: {salti}")
    config.FILE_METADATI.write_text(json.dumps(meta, indent=2, ensure_ascii=False), encoding="utf-8")
    ok = {r["ticker"] for r in meta["strumenti"] if r["stato"] == "ok"}
    mancanti = [t for t, _ in config.SETTORI] + [config.BENCHMARK[0], config.TICKER_CAMBIO]
    mancanti = [t for t in mancanti if t not in ok]
    if mancanti:
        raise SystemExit(f"Dati mancanti per: {', '.join(mancanti)}. Servono tutti i nove settori, il benchmark e il cambio.")


if __name__ == "__main__":
    main()

"""Passo 2 - Rotazione mensile tra nove ETF settoriali americani, con le condizioni di chi parte con 1.000 euro.

Legge SOLO i file in dati/ e produce in risultati/:
  metriche.json          ogni numero dell'articolo, con descrizione e origine di calcolo
  prove.csv              per regola e scenario: valore finale, rendimento annuo, ordini, costi, tasse, perdita massima
  scimmie_finali.csv     valore finale netto di ogni scimmia (scenario principale), per regola
  curve.csv              valore giorno per giorno (una seduta su cinque) di buy & hold, nove settori e rotazioni
  scelte.csv             il settore scelto a ogni ribilanciamento dalla rotazione principale

Regole: "bh" = buy & hold dell'ETF sull'S&P 500; "eq" = i nove settori comprati in parti uguali e tenuti; "r<L>_<K>" =
rotazione mensile verso i K settori con il rendimento più alto delle ultime L sedute. Quattro scenari: lordo (nessun costo,
nessuna tassa) e tre scenari di commissione, tutti con la tassa del 26%.
Scimmia: stessi giorni di ordine e stesso numero di ordini della regola, settori scelti a caso; gli stessi costi e le
stesse tasse, passati dallo stesso contabile.
"""
import json
import platform
from datetime import datetime, timezone

import numpy as np
import pandas as pd

import config
import simulazione as s

RIS: dict = {}
SORGENTE = "02_backtest_e_test.py con simulazione.py"
SCEN = [("lordo", 0.0, 0.0, 0.0)] + [(f"c{k}", f, p, config.ALIQUOTA) for k, (_, f, p) in enumerate(config.SCENARI_COSTO)]
M = f"c{config.SCENARIO_PRINCIPALE}"
NOME_SCEN = {f"c{k}": nome for k, (nome, _, _) in enumerate(config.SCENARI_COSTO)}
NOME_SCEN["lordo"] = "lordo"


def rid_rot(L: int, k: int) -> str:
    return f"r{L}_{k}"


R_PRINC = rid_rot(*config.PRINCIPALE)
R_SECOND = rid_rot(*config.SECONDARIA_SCIMMIE)
VARIANTI = [rid_rot(L, k) for k in config.N_SETTORI for L in config.LOOKBACKS]
NOME_REGOLA = {"bh": "buy & hold dell'S&P 500", "eq": "nove settori tenuti"}
for L in config.LOOKBACKS:
    for k in config.N_SETTORI:
        NOME_REGOLA[rid_rot(L, k)] = f"rotazione, {L} sedute, {k} {'settore' if k == 1 else 'settori'}"


def reg(chiave, valore, formato, descrizione, origine=SORGENTE):
    if isinstance(valore, (np.floating, np.integer)):
        valore = valore.item()
    if isinstance(valore, float) and not np.isfinite(valore):
        raise SystemExit(f"Numero non finito per {chiave}")
    RIS[chiave] = {"valore": valore, "formato": formato, "descrizione": descrizione, "origine": origine}


def holm(p: dict) -> dict:
    ordine = sorted(p, key=p.get)
    m = len(ordine)
    out, massimo = {}, 0.0
    for k, nome in enumerate(ordine):
        massimo = max(massimo, min(1.0, (m - k) * p[nome]))
        out[nome] = massimo
    return out


def bootstrap_blocchi(d: np.ndarray, rng) -> np.ndarray:
    """Medie di B ricampionamenti a blocchi circolari della serie d (lunghezza del blocco: config.LUNGHEZZA_BLOCCO)."""
    N, L = len(d), config.LUNGHEZZA_BLOCCO
    nb = int(np.ceil(N / L))
    medie = np.empty(config.N_BOOTSTRAP)
    passo = 250
    for a in range(0, config.N_BOOTSTRAP, passo):
        m = min(passo, config.N_BOOTSTRAP - a)
        inizi = rng.integers(0, N, size=(m, nb))
        idx = (inizi[:, :, None] + np.arange(L)[None, None, :]) % N
        medie[a:a + m] = d[idx.reshape(m, -1)[:, :N]].mean(axis=1)
    return medie


def main() -> None:
    config.RISULTATI.mkdir(parents=True, exist_ok=True)
    meta = json.loads(config.FILE_METADATI.read_text(encoding="utf-8"))
    stato = {r["ticker"]: r["stato"] for r in meta["strumenti"]}
    tickers = [t for t, _ in config.SETTORI] + [config.BENCHMARK[0]]
    for t in tickers + [config.TICKER_CAMBIO]:
        if stato.get(t) != "ok":
            raise SystemExit(f"Dati mancanti per {t}: {stato.get(t)}")
    chiusure = {t: s.carica_csv(config.file_dati(t)) for t in tickers}
    cambio = s.carica_csv(config.file_dati(config.TICKER_CAMBIO))
    date, nomi, C, FX = s.prepara(chiusure, cambio)
    n = len(date)
    anni_idx = date.year.to_numpy()
    col_sett = list(range(len(config.SETTORI)))
    col_spy = nomi.index(config.BENCHMARK[0])
    t_min = max(config.LOOKBACKS)

    piani = {}
    for L in config.LOOKBACKS:
        for k in config.N_SETTORI:
            piani[rid_rot(L, k)] = s.piano_rotazione(C, date, L, k, t_min, col_sett)
    i0 = min(min(p) for p in piani.values())
    if any(min(p) != i0 for p in piani.values()):
        raise SystemExit("Le regole non partono tutte nella stessa seduta.")
    piani["bh"] = {i0: (col_spy,)}
    piani["eq"] = {i0: tuple(col_sett)}
    anni_test = (date[-1] - date[i0]).days / 365.25
    if anni_test < config.STORIA_MINIMA_ANNI:
        raise SystemExit(f"Solo {anni_test:.1f} anni di test: troppo pochi.")
    REGOLE = ["bh", "eq"] + VARIANTI
    print(f"{n} sedute comuni dal {date[0].date()} al {date[-1].date()}; test dal {date[i0].date()} ({anni_test:.1f} anni); "
          f"{len(piani[R_PRINC])} ribilanciamenti")

    # --- Tutte le simulazioni (regola x scenario) --------------------------------------------------------------------
    sim = {}
    for rid in REGOLE:
        for sid, f, p, al in SCEN:
            sim[(rid, sid)] = s.simula(C, FX, anni_idx, piani[rid], i0, config.CAPITALE, f, p, al, serie=True)
    cg = {k: s.cagr(v["valore_finale_eur"], config.CAPITALE, date, i0) for k, v in sim.items()}
    prove = []
    for (rid, sid), r in sim.items():
        prove.append({"regola": rid, "scenario": sid, "finale": r["valore_finale_eur"], "cagr": cg[(rid, sid)],
                      "ordini": r["n_acquisti"] + r["n_vendite"], "commissioni": r["commissioni_eur"], "tasse": r["tasse_eur"],
                      "perdita_massima": r["perdita_massima"]})
    for (rid, sid), r in sim.items():
        print(f"  {rid:8s} {sid:6s} finale {r['valore_finale_eur']:9.1f}  cagr {cg[(rid, sid)]*100:6.2f}%  ordini {r['n_acquisti']+r['n_vendite']:4d}")

    # --- Scelte della rotazione principale ---------------------------------------------------------------------------------
    scelte = []
    prev: set = set()
    for i in sorted(piani[R_PRINC]):
        t = piani[R_PRINC][i]
        scelte.append({"data_ordine": str(date[i].date()), "settore": nomi[t[0]], "cambia": int(set(t) != prev)})
        prev = set(t)
    sc_df = pd.DataFrame(scelte)
    quota_cambio = float(sc_df["cambia"].iloc[1:].mean())
    conteggio = sc_df["settore"].value_counts()
    nome_sett = dict(config.SETTORI)

    # --- Le scimmie (rispetto alle due regole con L = 126) -------------------------------------------------------------------
    rng_s = np.random.default_rng([config.SEME, 1])
    scim = {}
    for rid in (R_PRINC, R_SECOND):
        finali = {sid: np.empty(config.N_SCIMMIE) for sid, *_ in SCEN}
        for j in range(config.N_SCIMMIE):
            pm = s.scimmia_piano(piani[rid], col_sett, rng_s)
            for sid, f, p, al in SCEN:
                finali[sid][j] = s.simula(C, FX, anni_idx, pm, i0, config.CAPITALE, f, p, al, serie=False)["valore_finale_eur"]
        scim[rid] = finali
        print(f"  scimmie {rid}: mediana netta {np.median(finali[M]):.0f}")

    # --- Bootstrap a blocchi: rotazione contro buy & hold (rendimento giornaliero netto, scenario principale) ---------------
    boot = {}
    e_bh = sim[("bh", M)]["equity"]
    for q, rid in enumerate((R_PRINC, R_SECOND)):
        e = sim[(rid, M)]["equity"]
        d = (e[1:] / e[:-1] - 1) - (e_bh[1:] / e_bh[:-1] - 1)
        medie = bootstrap_blocchi(d - d.mean(), np.random.default_rng([config.SEME, 2, q]))
        osserv = float(d.mean())
        p_boot = (int((np.abs(medie) >= abs(osserv)).sum()) + 1) / (config.N_BOOTSTRAP + 1)
        medie_ic = bootstrap_blocchi(d, np.random.default_rng([config.SEME, 3, q]))
        alfa = (1 - config.LIVELLO_CONFIDENZA) / 2
        lo, hi = np.quantile(medie_ic, [alfa, 1 - alfa])
        boot[rid] = dict(p=p_boot, diff=osserv * 252, lo=float(lo) * 252, hi=float(hi) * 252)

    p_sc = {rid: (int((scim[rid][M] >= sim[(rid, M)]["valore_finale_eur"]).sum()) + 1) / (config.N_SCIMMIE + 1) for rid in scim}
    famiglia = {f"sc_{rid}": p_sc[rid] for rid in scim} | {f"bo_{rid}": boot[rid]["p"] for rid in boot}
    ph = holm(famiglia)

    # --- Registro dei numeri ---------------------------------------------------------------------------------------------------
    reg("n_sedute", n, "int", "Sedute comuni a tutti gli strumenti e al cambio", "dati/")
    reg("data_inizio", str(date[i0].date()), "data_lunga", "Prima seduta del test (primo ordine di tutte le regole)", "dati/")
    reg("data_ultima", str(date[-1].date()), "data_lunga", "Ultima seduta presente nei dati", "dati/")
    reg("data_prima_serie", str(date[0].date()), "data_lunga", "Prima seduta con tutti i dati disponibili (cambio incluso)", "dati/")
    reg("anni", anni_test, "num1", "Anni del test")
    reg("n_ribilanciamenti", len(piani[R_PRINC]), "int", "Fine mese in cui la rotazione principale decide (dal primo ordine in poi)", "scelte.csv")
    reg("quota_mesi_cambio", quota_cambio, "pct0", "Quota dei ribilanciamenti in cui la rotazione principale cambia settore", "scelte.csv")
    top = conteggio.index[0]
    reg("settore_top_nome", nome_sett[top], "testo", "Settore scelto più spesso dalla rotazione principale", "scelte.csv")
    reg("settore_top_ticker", top, "testo", "Ticker del settore scelto più spesso", "scelte.csv")
    reg("settore_top_quota", float(conteggio.iloc[0] / len(sc_df)), "pct0", "Quota dei ribilanciamenti in cui la rotazione principale sceglie il settore più frequente", "scelte.csv")
    reg("n_settori_usati", int(len(conteggio)), "int", "Settori diversi scelti almeno una volta dalla rotazione principale", "scelte.csv")
    for rid in REGOLE:
        for sid in NOME_SCEN:
            x = sim[(rid, sid)]
            reg(f"{rid}_{sid}_finale", x["valore_finale_eur"], "int", f"Valore finale di {config.CAPITALE:.0f} euro ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})")
            reg(f"{rid}_{sid}_cagr", cg[(rid, sid)], "pct1", f"Rendimento annuo composto ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})")
        x = sim[(rid, M)]
        reg(f"{rid}_dd", -x["perdita_massima"], "pct0", f"Perdita massima dal picco ({NOME_REGOLA[rid]}, scenario principale)")
        reg(f"{rid}_ordini", x["n_acquisti"] + x["n_vendite"], "int", f"Ordini totali, acquisti e vendite, liquidazione finale compresa ({NOME_REGOLA[rid]})")
        reg(f"{rid}_ordini_anno", (x["n_acquisti"] + x["n_vendite"]) / anni_test, "num1", f"Ordini all'anno ({NOME_REGOLA[rid]})")
        for sid in NOME_SCEN:
            if sid == "lordo":
                continue
            reg(f"{rid}_{sid}_costo", sim[(rid, sid)]["commissioni_eur"], "int", f"Commissioni pagate in tutto ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})")
            reg(f"{rid}_{sid}_tasse", sim[(rid, sid)]["tasse_eur"], "int", f"Tasse pagate in tutto ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})")
        reg(f"{rid}_attrito", cg[(rid, "lordo")] - cg[(rid, M)], "pp1", f"Punti di rendimento annuo persi dal lordo al netto, scenario principale ({NOME_REGOLA[rid]})")
        # prima e seconda metà del periodo (equity netta dello scenario principale)
        e = x["equity"]
        mezzo = len(e) // 2
        a1 = (len(e[:mezzo]) / 252.0)
        a2 = (len(e[mezzo:]) / 252.0)
        reg(f"{rid}_cagr_meta1", (e[mezzo - 1] / e[0]) ** (1 / a1) - 1, "pct1", f"Rendimento annuo della prima metà del periodo, valore di mercato senza liquidazione ({NOME_REGOLA[rid]}, scenario principale)")
        reg(f"{rid}_cagr_meta2", (e[-1] / e[mezzo]) ** (1 / a2) - 1, "pct1", f"Rendimento annuo della seconda metà del periodo, valore di mercato senza liquidazione ({NOME_REGOLA[rid]}, scenario principale)")
    reg("data_meta", str(date[i0 + len(sim[("bh", M)]["equity"]) // 2].date()), "data_lunga", "Seduta che divide a metà il periodo di test", "dati/")
    for rid in (R_PRINC, R_SECOND):
        fin = scim[rid]
        for sid in NOME_SCEN:
            reale = sim[(rid, sid)]["valore_finale_eur"]
            reg(f"{rid}_{sid}_sc_mediana", float(np.median(fin[sid])), "int", f"Valore finale mediano delle scimmie ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})", "scimmie_finali.csv")
            reg(f"{rid}_{sid}_p_sc", (int((fin[sid] >= reale).sum()) + 1) / (config.N_SCIMMIE + 1), "pval", f"p-value a una coda: quota di scimmie che fanno almeno quanto la regola ({NOME_REGOLA[rid]}, scenario {NOME_SCEN[sid]})", "scimmie_finali.csv")
        reg(f"{rid}_sc_sotto", float((fin[M] < sim[(rid, M)]["valore_finale_eur"]).mean()), "pct0", f"Quota di scimmie che chiudono sotto la regola, scenario principale ({NOME_REGOLA[rid]})", "scimmie_finali.csv")
        reg(f"{rid}_sc_sopra_bh", float((fin[M] >= sim[("bh", M)]["valore_finale_eur"]).mean()), "pct0", f"Quota di scimmie che fanno almeno quanto il buy & hold, scenario principale ({NOME_REGOLA[rid]})", "scimmie_finali.csv")
        reg(f"{rid}_p_sc_holm", ph[f"sc_{rid}"], "pval", f"p-value delle scimmie corretto con Holm ({NOME_REGOLA[rid]}, scenario principale)", "scimmie_finali.csv")
        b = boot[rid]
        reg(f"{rid}_diff_ann", b["diff"], "pp1", f"Differenza media annualizzata del rendimento netto giornaliero tra la rotazione e il buy & hold, in punti percentuali ({NOME_REGOLA[rid]})", "bootstrap a blocchi")
        reg(f"{rid}_diff_lo", b["lo"], "pp1", f"Estremo inferiore dell'intervallo bootstrap a blocchi della differenza annualizzata ({NOME_REGOLA[rid]})", "bootstrap a blocchi")

  - azioni frazionate; commissione per ogni ordine = parte fissa + parte proporzionale all'importo investito o incassato;
  - la cassa non rende nulla; i dividendi non sono considerati (si usano le chiusure non corrette);
  - tassa sulle plusvalenze calcolate in euro (cambio incluso), pagata a ogni vendita come nel regime amministrato; la
    commissione si somma al costo di acquisto e si sottrae dall'incasso; le minusvalenze compensano le plusvalenze
    successive fino al quarto anno seguente;
  - a fine periodo si vende tutto, con commissione e tassa, per confrontare cifre nette.
Non modellati: imposta di bollo, tassa sulle transazioni finanziarie, spread di cambio, scarto tra denaro e lettera.
"""
from pathlib import Path

import numpy as np
import pandas as pd


class Zaino:
    """Minusvalenze compensabili con le plusvalenze successive, fino al 4° anno seguente."""

    def __init__(self, aliquota: float):
        self.aliquota = aliquota
        self.voci: list[list[float]] = []   # [ultimo anno utilizzabile, importo residuo]

    def tassa(self, anno: int, guadagno: float) -> float:
        if guadagno < 0:
            self.voci.append([anno + 4, -guadagno])
            return 0.0
        residuo = guadagno
        for voce in sorted(self.voci, key=lambda v: v[0]):      # prima le più vecchie
            if voce[0] < anno or voce[1] <= 0:
                continue
            usa = min(voce[1], residuo)
            voce[1] -= usa
            residuo -= usa
            if residuo <= 0:
                break
        return self.aliquota * residuo


def carica_csv(percorso: Path) -> pd.DataFrame:
    df = pd.read_csv(percorso, parse_dates=["Date"], index_col="Date").sort_index()
    df.index = pd.to_datetime(df.index).tz_localize(None).normalize()
    df = df[~df.index.duplicated(keep="last")]
    if (df["Close"] <= 0).any() or df["Close"].isna().any():
        raise SystemExit(f"{percorso}: chiusure mancanti o non positive.")
    return df


def prepara(chiusure: dict[str, pd.DataFrame], cambio: pd.DataFrame) -> tuple[pd.DatetimeIndex, list[str], np.ndarray, np.ndarray]:
    """Allinea le chiusure di tutti gli strumenti sulle sedute comuni (con cambio disponibile).
    Restituisce date, elenco dei ticker, matrice delle chiusure (sedute x strumenti) e vettore del cambio."""
    nomi = list(chiusure)
    tab = pd.concat({k: chiusure[k]["Close"].astype(float) for k in nomi}, axis=1).dropna()
    fx = cambio["Close"].astype(float)
    tab["__fx"] = fx.reindex(tab.index.union(fx.index)).ffill().reindex(tab.index)
    tab = tab.dropna()
    return tab.index, nomi, tab[nomi].to_numpy(float), tab["__fx"].to_numpy(float)


def fine_mese(date: pd.DatetimeIndex) -> np.ndarray:
    """Indici delle sedute che sono l'ultima del loro mese di calendario (l'ultima riga dei dati è esclusa)."""
    mese = date.year.to_numpy() * 12 + date.month.to_numpy()
    return np.flatnonzero(mese[1:] != mese[:-1])


def piano_rotazione(C: np.ndarray, date: pd.DatetimeIndex, lookback: int, k: int, t_min: int, colonne: list[int]) -> dict[int, tuple[int, ...]]:
    """Per ogni fine mese t >= t_min: i k strumenti (tra `colonne`) con il rendimento di prezzo più alto nelle ultime
    `lookback` sedute. Restituisce {indice della seduta di esecuzione (t+1): colonne scelte, in ordine di classifica}."""
    piano = {}
    for t in fine_mese(date):
        if t < t_min or t < lookback:
            continue
        rend = C[t, colonne] / C[t - lookback, colonne] - 1.0
        ordine = np.argsort(-rend, kind="stable")[:k]
        piano[int(t) + 1] = tuple(int(colonne[j]) for j in ordine)
    return piano


def _compra_importo(cassa: float, fissa: float, perc: float) -> tuple[float, float]:
    """Dalla cassa all'importo investito e alla commissione pagata: cassa = investito + fissa + perc*investito."""
    investito = (cassa - fissa) / (1.0 + perc)
    return investito, fissa + perc * investito


def simula(C: np.ndarray, FX: np.ndarray, anni: np.ndarray, piano: dict[int, tuple[int, ...]], i0: int, capitale: float,
           fissa: float, perc: float, aliquota: float, serie: bool = True) -> dict:
    """Esegue il piano {seduta: strumenti da tenere}. Alla prima seduta del piano si investe tutta la cassa."""
    n = C.shape[0]
    cassa = float(capitale)
    pos: dict[int, list[float]] = {}          # colonna -> [azioni, costo di acquisto in euro]
    zaino = Zaino(aliquota)
    comm_tot = tasse_tot = 0.0
    n_acq = n_ven = 0
    log: list[dict] = []
    storia: list[tuple[int, float, dict[int, float]]] = []

    def vendi(i, c, motivo):
        nonlocal cassa, comm_tot, tasse_tot, n_ven
        az, base = pos.pop(c)
        lordo = az * C[i, c] / FX[i]
        comm = fissa + perc * lordo
        netto = lordo - comm
        guadagno = netto - base
        tassa = zaino.tassa(int(anni[i]), guadagno)
        comm_tot += comm
        tasse_tot += tassa
        cassa += netto - tassa
        n_ven += 1
        if serie:
            log.append(dict(i=i, lato="vendita", col=c, motivo=motivo, azioni=az, commissione=comm,
                            incasso_netto_eur=netto, plusvalenza_eur=guadagno, tassa_eur=tassa))

    for i in sorted(piano):
        if i < i0:
            continue
        bersaglio = piano[i]
        for c in [c for c in pos if c not in bersaglio]:
            vendi(i, c, "rotazione")
        entranti = [c for c in bersaglio if c not in pos]
        if entranti and cassa > 0:
            quota = cassa / len(entranti)
            for c in entranti:
                investito, comm = _compra_importo(quota, fissa, perc)
                if investito <= 0:
                    continue
                az = investito / (C[i, c] / FX[i])
                pos[c] = [az, quota]
                comm_tot += comm
                n_acq += 1
                cassa -= quota
                if serie:
                    log.append(dict(i=i, lato="acquisto", col=c, motivo="rotazione", azioni=az, commissione=comm,
                                    spesa_eur=quota))
        if serie:
            storia.append((i, cassa, {c: v[0] for c, v in pos.items()}))
    ultimo = n - 1
    for c in list(pos):
        vendi(ultimo, c, "liquidazione finale")
    finale = cassa

    out = {"valore_finale_eur": finale, "rendimento_totale": finale / capitale - 1,
           "n_acquisti": n_acq, "n_vendite": n_ven, "commissioni_eur": comm_tot, "tasse_eur": tasse_tot}
    anni_tot = (ultimo - i0) / 252.0
    out["anni"] = anni_tot
    if not serie:
        return out
    equity = np.empty(n - i0)
    for j, (i, cs, az) in enumerate(storia):
        fine = storia[j + 1][0] if j + 1 < len(storia) else n
        val = np.full(fine - i, cs)
        for c, a in az.items():
            val = val + a * C[i:fine, c] / FX[i:fine]
        equity[i - i0:fine - i0] = val
    in_pos = np.array([bool(az) for (_, _, az) in storia])
    giorni_inv = 0
    for j, (i, cs, az) in enumerate(storia):
        fine = storia[j + 1][0] if j + 1 < len(storia) else n
        if az:
            giorni_inv += fine - i
    picco = np.maximum.accumulate(equity)
    out.update({"equity": equity, "operazioni": log, "perdita_massima": float((equity / picco - 1).min()),
                "quota_giorni_investito": giorni_inv / (n - i0)})
    return out


def cagr(finale: float, capitale: float, date: pd.DatetimeIndex, i0: int) -> float:
    anni = (date[-1] - date[i0]).days / 365.25
    return (finale / capitale) ** (1 / anni) - 1 if finale > 0 else float("nan")


def scimmia_piano(piano: dict[int, tuple[int, ...]], colonne: list[int], rng) -> dict[int, tuple[int, ...]]:
    """Una scimmia: stessi giorni di ordine e stesso numero di strumenti che entrano e escono a ogni ribilanciamento
    della regola, ma strumenti scelti a caso. Così il numero di ordini è identico a quello della regola."""
    out = {}
    prev_reale: set[int] = set()
    prev_m: list[int] = []
    for i in sorted(piano):
        T = set(piano[i])
        c = len(T - prev_reale)
        if not prev_m:
            nuovo = [int(x) for x in rng.choice(colonne, size=len(T), replace=False)]
        else:
            restano = len(prev_m) - c
            tieni = [int(x) for x in rng.choice(prev_m, size=restano, replace=False)] if restano > 0 else []
            altri = [x for x in colonne if x not in prev_m]
            entra = [int(x) for x in rng.choice(altri, size=c, replace=False)] if c > 0 else []
            nuovo = tieni + entra
        out[i] = tuple(nuovo)
        prev_m = nuovo
        prev_reale = T
    return out

def uguali(a, b, tol=1e-9):
    return abs(a - b) <= tol * max(1.0, abs(a), abs(b))


def mat(righe, fx=1.0):
    C = np.array(righe, float)
    return C, np.full(len(C), fx), np.full(len(C), 2020)
